# Lightkeeper + KORD BREACH Runbook

Bu rehber yalnızca KORD BREACH görevi değildir.

Akış:

1. Mevcut başlangıç noktasından Lightkeeper erişimini açar.
2. `To the Light` görev zincirini takip eder.
3. Lightkeeper fiziksel erişimi açıldıktan sonra KORD BREACH görev hattına devam eder.
4. Finalde `Among Strangers` achievement hedeflenir.

Gerçek runbook dosyasını bu klasöre:

```text
runbook.html
```

adıyla koy.

Temiz URL:

```text
/tarkov/guides/lightkeeper-kord-breach
```

Arka planda:

```text
/tarkov/guides/lightkeeper-kord-breach/runbook.html
```

dosyasına yönlenir.
